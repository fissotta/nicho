# NICHO — a current of adaptation

A calm, single-player, *flOw*-like game about bacterial adaptation to temperature, pH and salinity across eight real
extreme environments (Copahue volcano, Yellowstone, the Kairei vent field, Lake Magadi, Salar de Atacama, Arctic
permafrost brines). Random mutations at each division, selective sweeps, purifying selection, clonal interference,
acclimation, horizontal gene transfer, grazers and "kill-the-winner" phages; a niche map places your lineage among
15 real extremophiles.

Pure HTML + JavaScript + Canvas + Web Audio, no build step: runs on GitHub Pages. Spanish by default, English toggle.

Run locally: `python3 tools/serve.py` → http://localhost:8000. Details and sources (Spanish) in `LEEME.md`.

Microbial Ecophysiology Lab (Fundación Ciencia & Vida), 2026.
